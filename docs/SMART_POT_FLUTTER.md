# SmartPot Flutter 接入协议

本项目同时支持两种互不兼容的 BLE 固件。Flutter 必须在扫描阶段按名称路由，连接后不能混用协议。

| 设备名称前缀 | 协议 |
| --- | --- |
| `Soil Sensor-` | 既有 RYOBI Soil Sensor 二进制协议 |
| `SmartPot` | 本文的 SmartPot UTF-8 文本协议 |

扫描时仅展示上述两个前缀的设备，按设备 ID/MAC 去重。名称为空时不要当作可连接设备，因为无法判定协议。

## SmartPot 服务

服务 UUID：`6f3f0000-4f52-4f54-9a4f-000000000001`

| 特征 UUID | 名称 | 访问 | 数据 |
| --- | --- | --- | --- |
| `6f3f0001-4f52-4f54-9a4f-000000000001` | Light | 读写 | `on` / `off` |
| `6f3f0002-4f52-4f54-9a4f-000000000001` | Light sensor | 读 | UTF-8 文本（Lux） |
| `6f3f0003-4f52-4f54-9a4f-000000000001` | Pump | 读写 | `on`、`off` 或非负整数秒 |
| `6f3f0004-4f52-4f54-9a4f-000000000001` | Soil moisture | 读 | UTF-8 文本（%） |
| `6f3f0005-4f52-4f54-9a4f-000000000001` | Soil EC | 读 | UTF-8 文本 |
| `6f3f0006-4f52-4f54-9a4f-000000000001` | Soil temperature | 读 | UTF-8 文本（C） |
| `6f3f0007-4f52-4f54-9a4f-000000000001` | Light RGB | 读写 | `R,G,B`，每项 0-255 |
| `6f3f0008-4f52-4f54-9a4f-000000000001` | Plant config | 读写 | 逗号分隔的 `key=value` UTF-8 文本 |
| `6f3f0009-4f52-4f54-9a4f-000000000001` | Sensor history | 读写 | 分页命令和历史文本 |
| `6f3f000a-4f52-4f54-9a4f-000000000001` | Time | 读写 | 4 字节小端 Unix 秒时间戳 |

Flutter `flutter_blue_plus` 等库常以 `List<int>` 提供特征值。文本特征用 `utf8.decode(bytes).trim()` 读取，写入使用 `utf8.encode(value)`；不要把文本当成 Soil Sensor 的单字节数值解码。

## 连接与刷新

1. 连接超时设为 20 秒，随后发现服务和特征。
2. 写入当前 Unix 秒的 4 字节 little-endian 值到 Time 特征。
3. 读回 Time，允许与写入值相差最多 2 秒；校验失败视为连接失败。
4. 每 2 秒执行一次完整刷新，也提供手动刷新。
5. 必须顺序读取 Light、Light sensor、RGB、Pump、Moisture、EC、Temperature、Plant config、History。不要并发 GATT 读取，固件可能因并发访问溢出 BLE 任务栈。
6. 单项读取失败时保留其他项结果，并向 UI 显示该项错误。写操作成功后等待约 800ms 再刷新。

## 历史记录

向 History 特征顺序写入 `offset=0`、`offset=1` 等，然后读取响应，直到响应为 `end` 或包含 `more=0`。

响应例：

```text
c=0;t=24;n=5;more=1;1723456800:43.2:24.1:320;1723460400:42.8:24.3:280
```

- `c`：当前块序号。
- `t`：设备提示的总记录数。
- `n`：当前块记录数。
- 一条记录格式：`unixSeconds:soilPercent:temperatureC:lux`。
- 忽略元数据、空项和字段数不为 4 的损坏记录。
- 时间戳为 `0` 时显示 `--`。

UI 应提供时间、湿度、温度、Lux 的历史表与趋势图。Lux 与湿度/温度量纲不同，推荐使用第二 Y 轴。

## 控制和配置

手动控制只能在 `am=0`（MANUAL）时启用；水泵启动及定时浇水必须二次确认。

配置为逗号分隔的文本，支持：

```text
am=1,aw=1,al=1,le=0,l=35,h=50,d=30,i=60,ld=3600,li=3600,lon=300,loff=500,ace=1,cs=08:00,ce=17:00
```

| 字段 | 含义 |
| --- | --- |
| `am` | 自动模式，`0`/`1` |
| `aw` / `al` / `le` | 自动浇水 / 自动灯 / Lux 闭环，`0`/`1` |
| `l` / `h` | 土壤湿度低/高阈值，必须 `l < h` |
| `d` / `i` | 浇水时长/间隔，支持秒数、`30s`、`2m`、`1h`，均应大于 0 |
| `ld` / `li` | 灯最大亮灯时长/最小间隔，支持秒数、`30s`、`2m`、`1h` |
| `lon` / `loff` | Lux 开/关阈值，必须 `lon < loff` |
| `ace` | 照护时段开关，`0`/`1` |
| `cs` / `ce` | 照护开始/结束，`HH:MM`；启用时必须 `cs < ce` |

所有持续时间换算为秒后应限制在 `0..65535`。当 `ace=1` 时校验 `cs`、`ce` 的格式和顺序。配置写入失败时不要覆盖本地编辑内容。

## Soil Sensor 协议

`Soil Sensor-` 是另一套只读的二进制协议。不要使用 SmartPot 的文本读写、时间同步或控制 UUID。

### 服务和实时读数

实时服务 UUID：`00000000-0001-726f-736e-65536c696f53`

| 特征 UUID | 名称 | 格式 |
| --- | --- | --- |
| `01000000-0001-726f-736e-65536c696f53` | Reading toggle | 写入单字节 `0x01` 开启，`0x00` 关闭 |
| `02000000-0001-726f-736e-65536c696f53` | Moisture | `uint8 / 2`，单位 % |
| `03000000-0001-726f-736e-65536c696f53` | Temperature | `int8 / 2`，单位 C |
| `04000000-0001-726f-736e-65536c696f53` | EC | `uint8 / 20`，单位 mS/cm |
| `05000000-0001-726f-736e-65536c696f53` | Timestamp | 4 字节小端 Unix 秒；`0` 可回退为客户端当前时间 |

连接并发现服务后，先写入 `0x01` 到 Reading toggle，再每 3 秒读取上述四项。所有特征值是原始字节，不是 UTF-8 文本。断开时写入 `0x00`（如仍连接）并停止轮询。

### Soil Sensor 历史记录

记录服务 UUID：`00000000-0000-726f-736e-65536c696f53`。

记录特征 UUID 格式：`XXYY0000-0000-726f-736e-65536c696f53`，其中：

| 记录族 | `YY` | `XX` 范围 | 用途 |
| --- | --- | --- | --- |
| L2 | `00` | `00` 至 `17`（24 个） | 近 2 天 |
| L1 | `01` | `00` 至 `07`（8 个） | 近 2 小时 |
| Latest | `02` | `00` | 最新记录 |

每个特征值固定为 32 字节，含 8 个连续的 4 字节子记录：

| 字节 | 含义 |
| --- | --- |
| `b0` | 低 5 位为记录索引；高 3 位为子记录索引 |
| `b1` | 湿度，`uint8 / 2` % |
| `b2` | 温度，`int8 / 2` C |
| `b3` | EC，`uint8 / 100` mS/cm |

四个字节均为 `0x00` 代表空记录。注意 Soil Sensor 的实时 EC 是 `/20`，历史 EC 是 `/100`，不可统一处理。不同蓝牙库可能以字节交换形式返回 UUID；Flutter 连接失败时应尝试标准 UUID 和 16-bit/32-bit 字节交换变体，或根据已发现的服务、特征 UUID 做不区分大小写的匹配。

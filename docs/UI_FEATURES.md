# 土壤传感器 App — 功能清单（UI 设计需求书）

> 依据当前已实现代码整理。协议事实：GATT 实时读数 + 3s 轮询；历史 Latest/L1/L2。

## 一、信息架构（3 个页面 + 堆栈导航）

```
Scanner（扫描页）──点击设备──▶ SensorDetail（详情页）
        │
        └── 预留 Settings（设置页，当前为占位）
```

- 堆栈导航（标题栏返回），无 Tab
- 详情页标题栏「传感器详情」

## 二、扫描页（Scanner Screen）

**目的**：发现附近的土壤传感器并进入详情。

| 元素 | 说明 |
|---|---|
| 标题 | 「Soil Sensor」+ 副标题「附近设备（名称以 Soil Sensor- 开头）」 |
| 状态提示行 | 见状态表 |
| 设备卡片列表 | 设备名 / 设备 ID / RSSI 值 |
| 重新扫描按钮 | 仅非扫描中状态显示 |

### 状态表
| 状态 | 提示文案 |
|---|---|
| 扫描中 | 「扫描中…」 |
| 30s 结束 | 「扫描结束（30s 超时）」 |
| 权限被拒 | 「未获得蓝牙权限，请在系统设置中允许后重试」 |
| 空列表（扫描中） | 「未发现设备。设备可能处于休眠，请靠近并按下唤醒。」 |
| 空列表（结束） | 「点击重新扫描开始。」 |

### 数据与交互
- 设备名可能延迟到达 → 卡片支持「名称待定…」占位态
- 设备去重以 ID 为键（RSSI 实时刷新，不新增卡片）
- 点击卡片 → 进入详情页并自动连接

## 三、详情页（Sensor Detail Screen）

**目的**：实时读数 + 历史记录查看。

### 3.1 头部区
| 元素 | 说明 |
|---|---|
| 设备名 | 「Soil Sensor-XXXX」 |
| 连接状态行 | 「已连接，每 3 秒读数」/「连接中…」/「错误：xxx」/「未连接」 |
| 读数开关 | 已连接时「暂停读数」/「恢复读数」 |
| 断开按钮 | 常显 |

### 3.2 实时指标卡（3 张）
每张卡片：指标名 / 数值+单位 / 进度条 / 状态副文案；进度条颜色随状态变化。

**湿度 Moisture**：单位 `%`，max=50，1 位小数
- `--` 未读数；`<15 偏干` | `15-70 正常(绿)` | `70-90 暂不需` | `>90 过多(红)`

**温度 Temperature**：单位 `℃`，max=50，1 位小数
- `--` 未读数；`<18 偏冷(蓝)` | `18-28 适宜(绿)` | `28-35 偏暖(黄)` | `>35 过热(红)`

**EC**：单位 `mS/cm`，max=5，2 位小数
- `--` 未读数；`<0.8 偏低(蓝)` | `0.8-1.8 理想(绿)` | `1.8-2.5 偏高(黄)` | `2.5-4.0 警戒` | `>4.0 盐渍(红)`

### 3.3 最近更新时间
「最近更新」+ 传感器时间戳（`toLocaleString`）

### 3.4 历史记录区
| 元素 | 说明 |
|---|---|
| 区块标题 | 「历史记录」 |
| 3 按钮 | 读取 Latest / 读取 L1 / 读取 L2（未连接置灰） |
| 加载态 | 读取中 loading spinner |
| 错误提示 | 读取失败红色文案 |
| 历史曲线卡片 | 标题（「L1 近 2 小时」/「L2 近 2 天」）+ SVG 折线 + 图例 + 数据点计数 |

**曲线图约束**：三条折线（湿度绿 / 温度蓝 / EC 黄）；每次读取一张卡片；L1、L2 分开展示。

## 四、设置页（Settings Screen，占位）
- 当前仅静态说明文字
- 预留：阈值配置、单位换算、历史清理（**未实现**，设计可预留入口但标注暂不可用）

## 五、全局视觉规范（当前主题）
| Token | 值 |
|---|---|
| 背景 `#f5f6f8` | 卡片 `#ffffff` |
| 边框 `#e3e6eb` | 主文字 `#1b1f24` |
| 次要文字 `#6b7280` | 主色 `#2f6f4f`（绿，按钮/连接态） |
| 状态色 | 偏干/暖/警戒 `#e07a3a`/`#d4a02c`，正常 `#2f8f5b`，偏冷 `#3a7bd5`，警告 `#c0392b` |
